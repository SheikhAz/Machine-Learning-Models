# 🛍️ Mall Customer Segmentation

A Machine Learning clustering project that segments mall customers into different **customer personas** based on their **Annual Income** and **Spending Score**.

The project uses **K-Means Clustering** to identify groups of customers with similar spending behavior and income levels.

## 🎯 Project Overview

The dataset contains **200 mall customer records** with the following attributes:

| Feature | Description |
|---|---|
| `CustomerID` | Unique customer identifier |
| `Gender` | Customer gender |
| `Age` | Customer age |
| `Annual Income (k$)` | Annual income in thousands of dollars |
| `Spending Score (1-100)` | Spending score assigned to the customer |

For clustering, the project focuses on:

- **Annual Income (k$)**
- **Spending Score (1-100)**

`CustomerID` is removed because it is an identifier and does not provide useful information for customer segmentation.

## 🤖 Machine Learning Approach

### K-Means Clustering

The project uses **K-Means**, an unsupervised Machine Learning algorithm, to divide customers into groups based on similarity.

Before clustering:

1. Customer ID is removed.
2. Gender is converted into a numerical representation using one-hot encoding.
3. Features are standardized using `StandardScaler`.
4. Annual income and spending score are selected for the final clustering model.
5. The optimal number of clusters is determined using the **Elbow Method**.

### Optimal Number of Clusters

The Elbow Method is evaluated for values of `K` from **1 to 10**.

The project selects:

```python
optimal_i = 5
```

Therefore, the final K-Means model creates **5 customer personas**.

```python
KMeans(
    n_clusters=5,
    random_state=42,
    n_init="auto"
)
```

## 👥 Customer Personas

The five clusters represent different combinations of annual income and spending behavior.

Typical interpretations of the resulting clusters can include:

- Lower-income / lower-spending customers
- Lower-income / higher-spending customers
- Average-income / average-spending customers
- Higher-income / lower-spending customers
- Higher-income / higher-spending customers

> The exact characteristics of each persona should be interpreted from the cluster centers and visualization produced by the trained model.

## 📊 Visualization

The project visualizes the customer segments using:

- X-axis → Annual Income (k$)
- Y-axis → Spending Score (1-100)
- Color → Persona / Cluster ID

The resulting visualization shows the **5 customer personas** generated by K-Means.

## 💾 Saved Models

Two deployment artifacts are generated using `joblib`.

### K-Means Model

```python
joblib.dump(f_kmeans, "KMeans_Model.joblib")
```

This contains the trained K-Means clustering model.

### Data Scaler

```python
joblib.dump(deployment_scaler, "data_scaler.joblib")
```

The scaler is used to transform new customer income and spending-score values in the same way as the training data.

## 🔄 Prediction Workflow

For a new customer:

```text
Annual Income
      +
Spending Score
      ↓
StandardScaler
      ↓
K-Means Model
      ↓
Cluster / Persona ID
```

Example:

```python
import joblib

scaler = joblib.load("data_scaler.joblib")
model = joblib.load("KMeans_Model.joblib")

customer = [[60, 50]]

customer_scaled = scaler.transform(customer)
persona = model.predict(customer_scaled)

print(persona)
```
